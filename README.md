# CrashBeacon GitHub Pages

This folder is the public marketing, support, and privacy site for CrashBeacon.

## Publish

1. Create a GitHub repository for CrashBeacon and push this project.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the default branch and the `/docs` folder, then save.
5. Confirm these public URLs before App Store review:
   - Marketing URL: `https://GITHUB_USER.github.io/CrashBeacon/`
   - Support URL: `https://GITHUB_USER.github.io/CrashBeacon/support.html`
   - Privacy Policy URL: `https://GITHUB_USER.github.io/CrashBeacon/privacy.html`

The support button automatically derives the repository's GitHub Issues URL when hosted on GitHub Pages. To use a support email instead, set `supportEmail` in `assets/site.js`. To use a custom domain, set `repositoryURL` there as well.

No analytics, cookies, external fonts, or third-party scripts are used.
